Online, offline and data

Chat: GPT-6 Astra. Transcription: gpt-transcribe, with English and Polish in one recording. The chat builds a reversible draft. In the chat you can also calculate with one of the app's calculators: the model only recognizes the input, and the result is calculated by the app engine on this device (also offline, after reopening) — it is not an inspection or an approval of an installation; Power, Torque and Bender are available only in the Tools tab. A note or measurement dictated for the selected job is shown for review and saved only after you confirm it with a button; saved notes and measurements are corrected in the Jobs tab. Complete items can be saved to the selected job after checking; materials linked to the chat can also be corrected after checking a before/after comparison, with the history kept; other items are edited in the Jobs tab. This stage is not a verified AI Chat about code requirements.

It does not send the whole job documentation or photos. Audio reaches the API only after the recording is stopped; the app server does not save the recording to disk. What is sent is the content of this draft, the calculator input of this chat and the history of this chat; from the job only the identifier, the version number and the length of the notes. The store=false parameter is not a guarantee of zero retention at the provider.

The key stays on the server. The API is billed separately from ChatGPT. Pilot limit: 60 AI/transcription attempts per UTC day, with no automatic retry. It is a limit on calls, not a cost limit.

Private pilot PRIVATE-PILOT-8. The online server is needed only for signing in and for the AI chat. The first open needs internet and a sign-in. Once the page is fully prepared on this device, the draft, local Jobs, tools and installed content stay on this device and work without internet and without signing in again. Data from the Mac, older addresses or other devices is not imported, copied or overwritten automatically. Until the server is configured, AI is shown as unavailable, and Send and Speak stay disabled. This pilot is not an acceptance test on a physical iPhone.
