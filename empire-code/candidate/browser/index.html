Rozmowa: GPT-6 Astra. Transkrypcja: gpt-transcribe, z polskim i angielskim w jednym nagraniu. Rozmowa tworzy odwracalny szkic. Kompletne pozycje można po sprawdzeniu zapisać do wybranej roboty; materiały powiązane z rozmową można też poprawić po sprawdzeniu porównania przed/po, z zachowaniem historii; pozostałe pozycje edytuje się w zakładce Roboty. Ten etap nie jest zweryfikowanym AI Chat o przepisach.

Nie wysyła całej dokumentacji robót ani zdjęć. Audio trafia do API tylko po zatrzymaniu nagrania; serwer aplikacji nie zapisuje nagrania na dysku. Wysyłana jest treść tego szkicu i historia tej rozmowy. Parametr store=false nie jest gwarancją zerowej retencji u dostawcy.

Klucz pozostaje na serwerze. API jest rozliczane osobno od ChatGPT. Limit pilotażu: 60 prób AI/transkrypcji na dobę UTC, bez automatycznego ponawiania. To limit wywołań, nie kwotowy limit kosztów.

Prywatny pilot PRIVATE-PILOT-3. Serwer online jest potrzebny tylko do logowania i do rozmowy AI. Pierwsze otwarcie wymaga internetu i logowania. Po pełnym przygotowaniu strony na tym urządzeniu szkic, lokalne Roboty, narzędzia oraz zainstalowane treści pozostają na tym urządzeniu i działają bez internetu i bez ponownego logowania. Dane z Maca, starszych adresów ani innych urządzeń nie są automatycznie importowane, kopiowane ani nadpisywane. Dopóki serwer nie zostanie skonfigurowany, AI jest pokazywane jako niedostępne, a Wyślij i Mów pozostają wyłączone. Ten pilot nie stanowi odbioru na fizycznym iPhonie.
